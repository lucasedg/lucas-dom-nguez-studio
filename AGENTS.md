# Lucas Domínguez Studio

## Stack and commands

- This is a React 19 application built with TanStack Start, Vite, TypeScript, and Tailwind CSS 4.
- Use `npm run dev` for local development, `npm run lint` for static checks, and `npm run build` for a production build.
- Keep the committed lockfile consistent with the package manager used to modify dependencies. Do not add a second lockfile.
- Before handing off code changes, run `npm run lint` and `npm run build` when the environment permits.

## Application structure

- TanStack Start uses file-based routing in `src/routes/`. `src/routes/__root.tsx` is the document shell and must retain `<Outlet />` and `<Scripts />`.
- `src/routeTree.gen.ts` is generated by TanStack Router. Never edit it manually.
- The studio site is one continuous editorial narrative at `/`. Keep internal navigation on section anchors unless the requested feature genuinely needs a new route.
- `src/routes/index.tsx` contains the homepage sections, interactive page components, and the central `projects` catalog. Keep project metadata and imagery in that catalog so visual assets can be replaced without altering the layout.
- `src/styles.css` owns Tailwind theme tokens, shared editorial utilities, responsive rules, and motion rules. Prefer the existing `studio-*` tokens and reusable utilities over introducing page-specific hard-coded values.
- `src/assets/` holds local media. Preserve explicit image dimensions, useful alt text, and lazy loading for non-hero images.
- `src/components/ui/` contains reusable generated UI primitives. Prefer composing them or adding page components outside that directory; change a primitive only when its shared behavior needs to change.

## Design and interaction

- Follow the 2026 rebrand: carbón #1D1D1D, blanco roto #F7F5F2, naranja ácido #FF5B14 only as an accent (#C2410C for orange text on light backgrounds) and petróleo #132433 for special sections; Bebas Neue (uppercase) for headlines and Montserrat for everything else. The framing symbol and logo live in `src/components/brand.tsx`; never redraw or distort the symbol.
- Treat mobile as an intentional layout, not a scaled-down desktop view. Maintain the established responsive breakpoints and navigation behavior.
- Respect `prefers-reduced-motion` and use small, GPU-friendly transitions. Avoid animation that is decorative without helping hierarchy or feedback.
- Keep the public-facing copy and accessible labels in Spanish unless a requested content change calls for another language.

## Client and server boundaries

- The app is server-rendered. Put browser-only APIs such as `window`, `document`, observers, and event listeners inside client-safe React effects or guards.
- Preserve the error-handling flow in `src/start.ts`, `src/server.ts`, and `src/lib/error-*.ts` unless the task is specifically about server behavior.
- Keep `verbatimModuleSyntax` disabled in `tsconfig.json`; it is required for TanStack Start's client/server bundling.

## Change discipline

- Keep changes narrowly scoped. Do not redesign unrelated sections or reformat generated and untouched files.
- Use the `@/` alias for imports from `src/` where it improves clarity, and keep TypeScript strictness intact.
- When adding a new route, follow `src/routes/README.md` and let the router regenerate the route tree.
