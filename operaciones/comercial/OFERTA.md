# Oferta de prueba · Presentación visual de servicios

Uso interno. Precio inicial recomendado: **590 € antes de impuestos**, sujeto a validar costes y alcance. Calendario por confirmar. El [programa comercial](PROGRAMA-COMERCIAL.md) define el catálogo completo, los planes mensuales y el modelo económico.

## Cómo explicarla

«Te ayudo a presentar uno de tus servicios de forma clara y coherente con tu marca, con una ficha para enviar a tus clientes y piezas visuales para comunicarlo en redes.»

Para negocios que ya tienen identidad y material propio, y necesitan explicar mejor un servicio concreto. El resultado contratado son materiales terminados; no se prometen ventas, reservas ni alcance.

## Alcance base propuesto

| Entregable | Límite |
| --- | --- |
| Conversación inicial | Una sesión de 30 minutos sobre un servicio y un objetivo |
| Estructura del mensaje | Qué incluye, para quién es, dudas frecuentes y siguiente paso; validación técnica a cargo del cliente |
| Ficha comercial | Un PDF de hasta dos páginas para enviar por correo o WhatsApp |
| Piezas para redes | Tres diseños estáticos: servicio, proceso y resultado; cada uno adaptado a publicación vertical 1080 × 1350 y story 1080 × 1920; seis archivos finales |
| Revisiones | Dos rondas de comentarios agrupados dentro del alcance acordado |
| Entrega | PDF y archivos finales PNG/JPG; una explicación de uso de 20 minutos |

Una marca, un servicio y un idioma. Los textos breves se organizan a partir de información del cliente; no incluye investigación técnica del servicio. Los editables solo se incorporan si se detallan expresamente en el presupuesto.

## Qué necesitamos del cliente

Logo y guía de marca si existe; fotos utilizables con permiso; descripción e inclusiones del servicio; restricciones o condiciones; canal de contacto; persona que aprueba y fecha necesaria. Confirmar que el material disponible permite el resultado deseado antes de cerrar el alcance.

## Servicios adicionales, solo si hay necesidad

Fotografía/vídeo con presupuesto y disponibilidad del colaborador confirmados. Identidad nueva o rediseño como proyecto distinto. Web, desarrollo, traducciones, publicidad, publicación diaria y gestión de comunidad fuera del alcance base. Ningún coste externo se compromete sin incorporarlo al presupuesto.

Si el negocio ya explica bien sus servicios y tiene material suficiente, puede no necesitar esta oferta. Preguntar antes de vender.

Coste total = suma de horas × coste interno por hora + costes externos + contingencia.

Precio de referencia antes de impuestos = coste total / (1 − margen objetivo). El margen debe expresarse como decimal entre 0 y menos de 1; no confundirlo con un recargo sobre coste. Usar el mayor entre este resultado y el mínimo por proyecto como punto de revisión, no como precio aceptado automáticamente.

El programa comercial propone 590 € con una hipótesis de ocho horas y costes explícitos; no es una tarifa media de mercado. Faltan costes y capacidad reales para validar el margen. En el presupuesto comercial, detallar impuestos aplicables por separado conforme a la situación del estudio.

## Condiciones a concretar en cada propuesta

Fecha de inicio y entrega; importe y calendario de pago; persona que aprueba; formatos y editables; revisión de cambios fuera de alcance. El calendario se confirma cuando estén disponibles materiales, capacidad y aceptación. No prometer un plazo por defecto.

## Continuidad

Tras el primer proyecto, revisar si aparecen necesidades repetidas. Solo entonces definir una colaboración mensual con número de piezas, calendario, revisiones y coste propios. No vender una cuota indefinida antes de conocer la carga real.
